# ProcuraX frontend delivery plan

This roadmap keeps the history reviewable while covering the real backend surface and the B7A7 requirements. Each checkpoint is intended to be one meaningful conventional commit.

1. `feat: establish frontend foundation and design system`
2. `feat: add responsive public navigation and mobile menu`
3. `feat: build public platform and company pages`
4. `feat: add supplier directory with URL-synced discovery`
5. `feat: implement authentication API boundary and session state`
6. `feat: build validated login and one-click role access`
7. `feat: add buyer and supplier registration flows`
8. `feat: enforce protected routes and role-aware navigation`
9. `feat: create shared dashboard shell and feedback states`
10. `feat: build buyer RFQ workspace and creation wizard`
11. `feat: add buyer quotation evaluation and award flow`
12. `feat: build supplier opportunity and quotation workflows`
13. `feat: add role-aware purchase order management`
14. `feat: implement goods receiving and delivery tracking`
15. `feat: build invoice submission and review workflows`
16. `feat: integrate Stripe checkout and payment history`
17. `feat: add refunds disputes and notification center`
18. `feat: build admin verification operations and audit logs`
19. `feat: add admin analytics charts and financial reporting`
20. `chore: complete accessibility performance and deployment polish`

The sequence may be adjusted when API integration reveals a dependency, but each commit should remain independently understandable and buildable.
